# baoanViewer

大龍峒保安宮文物細部瀏覽。選一件文物，把手機螢幕朝上平放在桌面，整張原圖就像鋪在桌上，手機螢幕是看圖的窗口。

## 使用方式

1. 用手機開啟頁面，從 14 件文物中選一件。
2. 按「開始偵測」，允許使用動作感測器（iPhone 會跳出權限詢問）。
3. 把手機平放在桌面，水平儀變綠後保持不動約 1 秒完成校準。
4. 在桌面上滑動手機移動視窗，轉動手機時圖會固定在桌面上。拿起手機會暫停追蹤，放回後繼續。
5. 也可以用手指拖曳、雙指縮放。右上角小地圖顯示目前視窗在整張圖的位置。

沒有感測器的裝置（例如電腦）可以按「不用感測器，直接拖曳瀏覽」，用滑鼠拖曳、滾輪縮放、方向鍵移動。

## 部署

純靜態網頁，不需要建置，把整個資料夾放到任何靜態主機即可。手機的方向與動作感測器只在 HTTPS 下開放，請用 HTTPS 網址開啟，例如 GitHub Pages。

## 內容

- `index.html`、`window.css`、`window.js`：頁面本體。
- `artifacts.json`：14 件文物的名稱、殿別、來源影像編號與原圖尺寸。
- `images/`：每件文物一張封面原圖，維持原始解析度，重新壓成 JPEG。
- `thumbs/`：選單縮圖。

影像為 2026-10-21 現地拍攝，文物資料來自 `baoan-temple-3d` 專案，由該專案的 `tools/build_window.py` 產生。

## 已知限制

- 滑動距離由加速度計積分估算，慢速滑動可能偵測不到，長時間會有偏移。可在「設定」調整靈敏度或重新校準。
- 視窗的實際尺寸以一般手機螢幕寬度估算，不同手機的對應比例略有差異。
